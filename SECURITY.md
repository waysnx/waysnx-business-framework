# SECURITY

> Security policy for the WaysNX Business Framework (WBF).

---

# Supported Versions

The following versions of the WaysNX Business Framework are currently supported with security updates and maintenance.

| Version | Supported |
|---------|:---------:|
| 1.x.x | ✅ Yes |
| < 1.0.0 | ❌ No |

---

# Reporting a Security Issue

If you discover a security issue related to this repository, please **do not create a public GitHub issue**.

Instead, report the issue privately so it can be investigated and addressed before public disclosure.

Please include as much information as possible:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)
- Supporting evidence or screenshots (if applicable)

---

# Response Process

Once a report is received, the maintainers will:

1. Acknowledge receipt of the report.
2. Assess the severity and impact.
3. Investigate the reported issue.
4. Develop and validate a fix if required.
5. Coordinate a responsible disclosure.
6. Publish the fix in a future release if applicable.

---

# Scope

This policy applies to:

- Repository documentation
- Framework specifications
- Templates
- Examples
- Governance documentation
- Review process documentation

Future companion tools, including the **WaysNX Development Quality Platform (DQP)**, will maintain their own security policies where appropriate.

---

# Responsible Disclosure

We appreciate responsible disclosure of potential security issues.

Please allow reasonable time for investigation and remediation before publicly disclosing vulnerabilities.
