# Bug Reports

If you discover an issue with the framework documentation, templates, or repository, please create a GitHub Issue with:

- A clear description
- Steps to reproduce (if applicable)
- Expected behavior
- Actual behavior
- Suggested improvement (optional)

---

# Feature Requests

Suggestions for new specifications, templates, documentation, or framework capabilities are welcome.

Before submitting a request:

- Review the roadmap
- Search existing issues
- Provide a clear business or engineering justification

---

# Questions

If your question is not answered in the documentation or FAQ, please use the project's GitHub Discussions (if enabled) or create an issue using the appropriate category.
